# Third-party components

The MIT license in `LICENSE` covers this project's own source. It does not
relicense third-party code, runtimes, models, or assets.

## What is actually in this repository

- **Bundled audio:** `assets/music/*.wav` and `assets/sfx/*.wav` are original
  procedural synthesis generated by `scripts/generate_assets.py`, declared
  CC0-1.0 in `assets/music/licenses.json` and `assets/sfx/licenses.json`. No
  third-party samples are included.
- **Optional models:** not committed. `models/README.md` explains that
  whisper.cpp GGML and optional Kokoro/MLX weights are downloaded separately;
  their upstream licenses and usage terms apply.
- **Runtime binaries:** not committed. Packaged builds bundle FFmpeg, a Python
  runtime, Electron, and a whisper.cpp runtime; those components keep their own
  licenses and notices.

## Dependencies installed at build time

The frontend uses React, React DOM, React Router, TypeScript, Vite, Tailwind,
PostCSS, and Autoprefixer. The backend uses Python packages including FastAPI,
Starlette, Uvicorn, Pillow, and SQLite bindings. These are installed from their
respective package managers and are governed by their own licenses; they are not
vendored into this repository.

## Packaged-app notices

If you redistribute a packaged `.app`, `.dmg`, or `.zip`, include the license
texts for the exact bundled FFmpeg build, whisper.cpp runtime, Python runtime,
Electron, and any model weights you choose to ship. The source-only MIT license
does not cover those components.
