## 6b. Engine B (AI Auto-Clip Studio) — implemented and measured (2026-11-17)
- **Code:** `backend/app/clip/` (models, store, probe, audio, transcribe, prompt, direction, highlights, metadata, render, jobs, api), `/api/clip/*`, `frontend/src/pages/ClipStudio.tsx` + `ClipProject.tsx`, `frontend/src/components/Prompter.tsx`, `frontend/src/lib/director.ts`, `backend/tests/test_clip_prompt.py` + `test_clip_direction.py` + `test_clip_render.py`, `scripts/engine_b_e2e.py`, `scripts/engine_b_asr_wer.py`, `scripts/engine_b_longrun.py`, `scripts/install_whisper_cpp.sh`.
- **Director/prompter:** `prompter-rules/v1` parses the brief into transparent scoring rules and `direction.py` builds the deterministic plan — preset, target durations, and in one-clip mode the assembly metadata. Five built-in set prompts plus free text are supported; `/api/clip/prompt/presets`, `/api/clip/prompt/parse` and `/projects/{id}/direction/preview` expose the flow. There is no model, network call or desktop LLM bridge. The plan is stored in job `meta`; the brief, rules, weights, components and grounded copy appear in each candidate's `score_json`, including an auditable `brief_fit` component.
- **Auto-clip to one assembled video (opt-in):** the prompter's **One clip** toggle is available on `/clip` and in `/clip/:id`; the category choice is carried into new projects and project changes persist. With it on, the director instruction includes `Mode: single-clip` and asks for 2–6 ordered `segments`, each a contiguous transcript sentence range with a narrative role. Silence gaps and visual scene cuts are included as boundary/support evidence; transcript sentence ranges remain the authority. The validator rejects invalid spans, overlaps, roles, durations and ungrounded copy, while local rules fill missing scenes. `count` is forced to 1 and exactly one selected candidate is created ready to render: its timeline is `0 → total duration`, source ranges remain in `segments`, and `assembly`/`segments` plus `single_clip` are stored in job `meta` and `score_json.params`. Boundary edits on assembled candidates return HTTP 400; multi-clip mode remains unchanged. **Short-source handling:** `_limit_assembly_to_source()` in `highlights.py` receives the uploaded file's real `duration_sec` in one-clip mode and clamps sentence, word, silence-gap and scene-cut boundaries plus the target duration before scoring; candidates record `assembly.clamped_to_source_duration`. If only one usable sentence remains, one transcript-grounded scene is emitted with a notice instead of raising `Source is too short for transcript-grounded assembly`. `_render_one()` independently clamps legacy assembly segments to the source, preventing `Assembly segment extends outside the source duration`. Two regressions cover the clamped multi-sentence case and the single-sentence case; the UI smoke's 2 s final-preview source exercises the render-time path.

## 7. Honest capability notes
- **Local/offline, no paid APIs:** yes (macOS `say`, FFmpeg, Pillow, deterministic script, loopback-only backend). Internet not required for generation.
- **Kokoro/Whisper.cpp:** Kokoro MLX is **not installed/verified** (adapter + fallback implemented); macOS `say` is the proven Engine A narration path. whisper.cpp `base.en` **is** installed, built locally and measured for Engine B (1.01 % WER on clean synthetic TTS, native word timings); SRT/VTT import remains the verified manual path and ASR is never simulated.
- **Engine B reframing:** deterministic geometry only — no face/subject tracking; no virality prediction from highlight scores. Planning is fully local: `prompter-rules/v1` parses the brief and the director builds a deterministic plan. No model is consulted and no invented copy is ever generated.
- **Diffusion video:** not enabled on 8 GB; visuals are **animated graphics/stills** (labeled), not AI-generated footage.
- **Narration-driven duration:** outputs may exceed nominal targets (e.g. 5-min target → 329 s at measured speech rate).
- **Unsigned app / packaged UI:** Gatekeeper override may be needed; dev Electron UI is click-tested by `scripts/ui_smoke.cjs` (25/25 PASS), and the rebuilt installed app was checked through CDP for the prompter, captions, one-clip and transitions toggles plus assembled-video copy on both the category page and a project.
